# Smart Expense Tracker 💰

A Java-based desktop application for managing and analyzing personal expenses. The application provides a simple interface for recording expenses, viewing spending information, and generating useful financial summaries.

## ✨ Features

- 🔐 User login interface
- 💸 Add and manage expenses
- 📊 View expense statistics
- 📈 Dashboard for financial overview
- 📅 Daily expense summaries
- 🗂️ Expense management and categorization
- 💾 Persistent expense data storage
- 🖥️ Desktop-based graphical user interface

## 🛠️ Tech Stack

- **Language:** Java
- **GUI:** Java Swing
- **IDE:** IntelliJ IDEA
- **Data Storage:** Text file-based storage
